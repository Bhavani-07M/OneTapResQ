# 🚑 OneTapResQ

OneTapResQ is a Smart roadside emergency assistance platform built using Streamlit, Python, and SQLite.

The platform is designed to provide quick, reliable, and accessible roadside support during vehicle emergencies such as fuel shortages, mechanical breakdowns, EV charging issues, and emergency safety situations.

OneTapResQ combines live location tracking, community-driven support, emergency safeguard systems, and smart assistance services into one unified platform with a modern, interactive, and responsive user interface.

The main objective of the project is to improve roadside safety and reduce response time during emergencies by providing instant access to nearby assistance services.

# 🚀 How to Run Locally

## Clone Repository

```bash
git clone https://github.com/Bhavani-07M/OneTapResQ.git
```

## Navigate to Project Folder

```bash
cd OneTapResQ
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

## Run Streamlit Application

```bash
streamlit run app.py
```
